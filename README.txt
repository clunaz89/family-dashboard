LUNA FAMILY DASHBOARD

Files:
- index.html
- manifest.json
- sw.js

The dashboard includes:
- Camila ($25/week, Monday-Friday)
- Addy ($20/week)
- Ayvah ($10/week)
- Sophia ($5/week, helper chores)
- Rotating chores and weighted points
- Parent PIN and approvals
- Editable/addable chore library
- Sunday payday calculations
- Basic family calendar
- Local device storage

IMPORTANT:
To install this as an iPad Home Screen web app with offline support, host this folder on an HTTPS website (for example GitHub Pages, Cloudflare Pages, or Netlify). Then open the hosted URL in Safari and choose Share > Add to Home Screen.

Version 1 stores data in Safari on that device. Clearing Safari website data can erase it. It does not yet sync to another iPhone/iPad.
